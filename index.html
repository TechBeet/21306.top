// PROJECTS & REPOSITORIES

开源项目与核心作品

以下项目均已在 GitHub 开源，涵盖下载工具、LLM 控制台、流量分析、插件汉化等多个技术领域。

📹

ClassIn-DL Rust · Iced

基于 Rust + Iced 框架重写的 ClassIn 课程视频高速解析下载工具。支持从剪贴板智能解析课程请求头，多线程并发下载与断点续传，并配有现代化的响应式界面，可灵活调节并发数与筛选视频质量。

剪贴板解析 断点续传 跨平台
[GitHub] [Releases] Active
🔍

FlowLens Rust

Windows 原生无代理 HTTP/HTTPS 抓包与调试工具。通过 WFP、ETW 和本地根证书在系统协议栈中就地观察、解密流量，并支持进程归属（PID/路径）、HTTP/2、WebSocket 与 gRPC 解析，甚至集成了 MCP Server 供 AI Agent 查询。

无代理抓包 进程归属 MCP Server
[GitHub] Active
🦙

LlamaUI Rust · Tauri 2

基于 Tauri 2.x 的 LLM 本地部署桌面控制台，为 llama-server（llama.cpp）提供图形化管理。支持自动检测模型与可执行文件，提供普通/高级/专业三种参数模式，并具备 CPU/内存/GPU 实时性能监控与安全沙箱。
⚠ 由于过大的维护压力，项目已于 2026.10.13 暂停更新。

LLM 本地部署 性能监控 已暂停维护
[GitHub] [Releases] Archived
🎨

Blender 插件汉化 Python

精选 7 款 Blender 插件的简体中文汉化版本合集。涵盖 BlenderMCP（AI 辅助建模）、BlenderGIS（GIS 数据导入）、Blenderkit（3D 素材库）、Blosm（真实地形）、Quicksnap（快速吸附）、Step-importer（STEP 导入）与 Super-io（万能导入导出）。每个插件均提供原始版与汉化版 .zip 包，一键安装。

7 款插件 Blender 3.0+ MIT
[GitHub] Active
🧱

PCL-OpenCN VB.NET

基于 Plain Craft Launcher (PCL) 的分支版本，移除了原版中针对国内连接的限制，让 Minecraft 玩家能够更自由地使用这款广受欢迎的启动器。该项目属于社区维护的衍生版本。

Minecraft 启动器 社区分支
[GitHub] Active
