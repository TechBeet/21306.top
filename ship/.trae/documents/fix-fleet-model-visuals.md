# 船队模型视觉与结构缺陷修复计划

## Summary

对五船场景做一次全面体检，修复三类问题：**船帆朝向系统性错误**（4 艘新船的硬帆被建成了纵帆姿态）、**木质构件无贴图**（广船全船用纯色铁力木材质，长船 UV 缩放把木纹压成纯色）、以及**结构缺陷**（泉州中桅悬空、蓬莱主桅穿不过桅孔、帆与桅穿插、黑石号无舵、宝船无舵叶）。修复后五船在斜侧视角下帆面朝向符合各自帆型，木质构件恢复可见木纹，缺失的舵类推演件补齐并明确标注。

## 现状分析（实测结论）

坐标约定：船长沿 X，船宽沿 Z，高度沿 Y，水面 y=0。

### 一、帆朝向

| 船 | 帆型 | 行号 | 当前几何 | 实测法线 | 结论 |
| --- | --- | --- | --- | --- | --- |
| 泉州 | 横帆 | ~4105-4137 | 自建 BufferGeometry，宽沿 Z、高沿 Y | ±X | 正确 |
| 蓬莱 | 硬帆（横） | 1878 / 1889 | `PlaneGeometry(14.7,15.6)`、`(4.6,6.8)`，无旋转 | ±Z | **错误** |
| 黑石号 | 三角纵帆 | 2353-2357 | `ShapeGeometry`，顶点 x −8.6…+9.8 | ±Z | 朝向符合纵帆，但**宽度 18.4 m 过大**（船长 21 m） |
| 广船 | 硬帆（横） | 2593 | `PlaneGeometry(sw,sh)`，无旋转 | ±Z | **错误 ×3** |
| 宝船 | 硬帆（横） | 2783 | 梯形 `ShapeGeometry`，无旋转，position z = 桅半径+0.05 | ±Z | **错误 ×6**；帆偏 Z 0.65 m |

补充：宝船帆中心落在桅杆半径之外（不穿插）；蓬莱、广船、黑石号的帆中心 z≈0.06–0.12，**落在桅杆半径内，与桅穿插**。

### 二、无贴图

- `woodMat()`（3417-3427）生成 map / bumpMap / roughnessMap 三贴图，`MAT.pine/camphor/fir/oak/deck/teak` 均带贴图。
- **`MAT.ironwood`（3441）是纯色 `MeshStandardMaterial`，无任何贴图** —— 广船全船（龙骨、壳板 12×11×2、56 肋骨、8 舱壁、尾封板、大擸、甲板、多孔舵）与宝船 11.07 m 舵杆全部使用它。
- 帆、绳、缝合孔、填料、钉为设计上的纯色件（`sailMat` ×3 处、`holeMat`、`ropeMat`、`caulkMat`、`MAT.sail/rope/iron`）。
- 其余新船木构件**均有 uv**（龙骨 ExtrudeGeometry + `mergeWithUV`；壳板手写 uv；舱壁/尾封板/甲板 ExtrudeGeometry 自带 uv），不存在"缺 uv 导致贴图丢失"。
- 长船木纹趋近纯色的真实原因：`buildPlankShell` 的 uv 为 `u = x*0.30`，宝船 71 m 使纹理重复 21 次，配合远距 mipmap 退化为平均色；且共享材质的 `repeat(2,2)` 无法按船区分。

### 四、已确认正常，不改动

- 四船舵件朝向正确（蓬莱 Box 法线 ±Z、广船 Extrude 法线 ±Z、泉州舵承座 22° 斜孔）。
- `attach()` 的 `material.clone()` 会保留贴图引用，贴图不会因克隆丢失。
- 五船吃水、布局、无相互穿插、无浮空（上一轮已实测）。

## 修复方案

### P0-1 帆朝向修正

统一规则：**横帆**（蓬莱、广船、宝船）帆宽沿 Z、法线沿 X，需 `rotation.y = Math.PI/2` 并沿 X 偏移到桅侧；**纵帆**（黑石号）保持法线沿 Z，仅缩小尺寸。

1. **蓬莱主帆 / 尾帆**（`SHIP_BUILDERS.pengla` 内）
   - 主帆：`mainSail.rotation.y = Math.PI/2`；`position.set(2.0 - 0.62, 5.73 + 15.6/2, 0)`（帆宽 14.7 m 沿 Z 居中，帆面挂在桅的船尾侧，偏移量取桅半径 0.54 + 0.08）
   - 尾帆：同上，`position.set(-9.0 - 0.24, 1.80 + 6.8/2, 0)`
   - 帆尺寸不变（14.7×15.6 = 229.3 m² 对应文档 229.5 m²；4.6×6.8 = 31.3 m² 对应 31.2 m²）
2. **广船三帆**：`sail.rotation.y = Math.PI/2`；`position.set(m.x - 0.55, 1.05 + 1.6 + sh/2, 0)`（三面帆共用同一朝向，X 偏移统一取桅半径 + 0.1）
3. **宝船六帆**：`sail.rotation.y = Math.PI/2`；`position.set(m.x - (rb + 0.12), DECK_UPPER + 0.20, 0)`（帆宽沿 Z 居中，不再偏 Z）
4. **黑石号三角帆**：顶点 X 范围由 −8.6…+9.8 缩为 −4.2…+4.6（跨约 8.8 m），顶点 y 保持；`position.z` 由 0.12 改为 `0.28`（桅半径 0.22 + 0.06），避免穿插；朝向不变（纵帆法线 ±Z 正确）

> 视觉影响说明：硬帆转为横帆后，从正侧方（沿 Z 看）会看到帆的窄边，这是物理正确的表现；斜侧视角（默认机位、`orbit` / `fleet`）仍能看到完整帆面。不改默认机位。

### P0-2 贴图修复

1. **铁力木改为带贴图材质**
   - `MAT.ironwood = woodMat('#3a2a20', '#150c06', 2, 5, 131)`（深色铁力木，纹理比松杉更密）
   - 保留 `side: THREE.DoubleSide`：`woodMat` 已内置 DoubleSide，无需额外处理
   - 广船与宝船舵杆自动继承，无需改 builder
2. **壳板 UV 按船长自适应**
   - 在 `buildPlankShell` 内取 `ctx.profile.length`，把 `u = x*0.30` 改为 `u = x / Math.max(1.5, ctx.profile.length / 8)`
   - 效果：每船木纹约重复 8 次，宝船不再被压成纯色；泉州船不受影响（走 legacy 路径）
3. **帆布纹理**
   - 新增 `function sailClothMap(seed, tint)`：256×256 canvas，米色底 + 竖向经线（间距 3 px，明度扰动 ±6%）+ 稀疏污渍；返回 `CanvasTexture`（SRGB、RepeatWrapping、repeat 4×6）
   - 新增 `function sailClothMat(seed, tint, opacity)`：基于该贴图构造 `MeshStandardMaterial`（roughness 0.96、DoubleSide、透明）
   - 替换三处自建 `sailMat`（蓬莱 1851、广船 2567、宝船 2744）；黑石号改用 `sailClothMat` 并带浅赭色
   - `MAT.sail` 同步替换为 `sailClothMat`
4. **绳索纹理（低成本）**
   - `ropeMat` 与 `MAT.rope` 增加 `bumpMap`（细密横向条纹 canvas，repeat 12×2），保留现色

### P1 结构修复

1. **S1 泉州中桅悬空**
   - 找到中桅的 `CylinderGeometry`/`Box` 创建处（RIG 段），保持桅顶世界坐标不变，把桅底从 `deckY(6.6)` 下移到桅座顶面 `0.57 + 0.02`
   - 具体做法：桅高由 `top - bottom` 重算，`position.y = (top + bottom)/2`；若桅为 Box 则同步 height
   - 详情卡 dims 增加「桅底坐于桅座顶面」
2. **S3 蓬莱主桅穿桅孔**
   - 桅杆改为两段：底部「桅脚」高 2.2 m、直径 0.24 m（穿 260 mm 方孔）；上部由 0.24 m 锥形过渡到 0.54 m 头径，直至总高 26.72 m
   - 用两段 `CylinderGeometry` 合并为一个 mesh，或直接用一个 `CylinderGeometry(0.27, 0.12, h)` 再叠加下部细柱；保持单一 PART id
   - 详情卡注明「桅脚 240 mm 穿 260 mm 桅孔，头径 540 mm」
3. **S4 蓬莱前桅空置**
   - 补一根前桅：高 15.5 m（推演）、底径 0.30 m、x=−6.0，桅底对齐前桅座孔（200 mm 方孔 → 桅脚 0.19 m）
   - 加一面前帆 5.2 × 6.4 m（推演），横帆朝向同上
   - 全部标 `grade:'C'`，note 注明「前桅高度与帆面为推演」
4. **S5 黑石号补舵**
   - 尾柱处（x≈−7.4）建舵：舵杆 φ140 mm、高 4.2 m；舵叶梯形 1.9 × 2.4 m，法线 ±Z
   - `grade:'B'`，`source:'inferred'`，note「黑石号舵未保存，按同时代 dhow 比例推演」
5. **S6 宝船补舵叶**
   - 宝船自身尾柱（x≈−31.5）建舵杆 φ0.6 m、长 8.0 m（推演），舵叶按文档小方案 **6.0 × 2.8 m = 16.8 m²**，法线 ±Z
   - `grade:'D'`，note 注明「按 16.8 m² 方案推演；遗址 11.07 m 舵杆为独立参照，不绑定」
   - 保留原有 11.07 m 舵杆参照物不动
6. **S7 帆桅穿插**：已在 P0-1 各项的 X 偏移与 z 位置中解决
7. **S8 三角帆缩放**：已在 P0-1 第 4 项解决

### P2 细节（可选，随 P0/P1 一并做）

- 宝船桅底由 `-4.60`（船底）上移到内底 `-4.05`，避免桅杆插入龙骨内部；桅顶 33.40 保持不变，故桅长相应缩短。详情卡总高仍写 38 m（自基线起算），并在 note 说明「桅脚埋入内底」。
- 宝船帆底 y 由 `DECK_UPPER + 0.20` 保持，确认与上甲板无穿插。

## 决策与假设

1. **帆型判定**：蓬莱/广船/宝船按中式硬帆（横帆）处理 —— 帆宽沿船宽、法线沿船长；黑石号按阿拉伯 lateen（纵帆）保留法线沿船宽。依据是文档对宝船「福船硬帆」、黑石号「三角帆」的描述。
2. **不修改泉州船的既有帆几何**，只修中桅悬空（S1）。
3. **推演件一律标注**：黑石号舵（B 级）、宝船舵叶（D 级）、蓬莱前桅与前帆（C 级）都在 `dimTable` 用 `inferred`，详情卡显示「推演」标签。
4. **不新增外部资源**：帆布、绳索、铁力木纹理全部用 canvas 程序化生成，保持单文件零依赖。
5. **不改动**：水面、天气、参数面板、船队布局、精度筛选、相机逻辑。
6. **泉州头桅/尾桅无桅座属史料合理**，保留并在详情卡补充说明，不补几何。

## 风险与回滚

- 帆转向后正侧视角只见窄边，属正确表现；若用户更偏好"满帆"观感，可只改 `rotation.y` 而不改偏移，或整体机位偏 15°（本次不做）。
- 泉州中桅下移会改变既有外观，但属修复缺陷；若需回滚，仅需恢复桅底 y 值。
- 铁力木改为贴图后颜色会略变浅，可调 `woodMat` 的 base/dark 色值微调。
