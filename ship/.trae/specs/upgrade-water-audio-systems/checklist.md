# Checklist

## 海浪
- [x] 海面由涌浪 / 风浪 / 碎浪三组共 9 个波分量叠加，形态不再是规则条纹
- [x] 波浪传播速度随重力 g 改变（调低 g 后明显变慢）
- [x] 波峰挤压处出现白浪，且随波陡/风暴增强而增多
- [x] 五档天气预设切换后浪高、周期、白浪比例同步变化

## 泡沫场
- [x] 泡沫纹理为世界空间、随时间漂移，不是整屏噪声
- [x] 白浪生成后有拖尾，并在数秒内消散
- [x] 船体吃水线周围持续生成泡沫并向外漂移
- [x] 关闭泡沫参数后海面不再出现白浪与泡沫环

## 浪花粒子
- [x] 风暴下船首/船舷出现抛物线水花，落回水面
- [x] 冲击越强，水花数量、初速、尺寸越大
- [x] 粒子在 0.6–1.6 s 内淡出，无残留白点
- [x] 粒子池复用，长时间运行不出现数量增长或卡顿

## 水体体积
- [x] 浅滩处水色青绿、半透明，可见沙底
- [x] 深水区呈深蓝且更不透明，颜色连续过渡
- [x] 浅滩边缘有白色泡沫带
- [x] 「水面半透」开启时仍能观察船体水线以下结构

## 环境声
- [x] 首次点击后环境声淡入，静音开关可整体关闭
- [x] 环境声随浪高/波周期变化（风暴时更响、更闷）
- [x] 晴天、小雨、大雨、薄雾、风暴各有可辨识的声音差异
- [x] 切换天气时 1.5 s 内交叉淡变，无爆音/断音

## 碰撞与混响
- [x] 强拍水时听到低频撞击 + 水花声，弱拍时几乎不可闻
- [x] 撞击声随撞击位置左右声像变化
- [x] 混响湿声与衰减可调，关闭后声音明显变干
- [x] 无 AudioContext 的环境下页面正常、无报错

## 参数与 UI
- [x] 面板新增「声音」标签，含总开关、总音量、环境、音效、混响湿声/衰减
- [x] 水体细节参数（浪高、白浪阈值、泡沫半衰期、浅滩开关）可调且生效
- [x] `ShipApp.setWaterParams` / `setAudioParams` / `setSeaState` 可用
- [x] 声音与水体设置刷新后保持（localStorage）

## 性能与兼容
- [x] 桌面端 ≥55 fps，移动端 ≥30 fps
- [x] 泡沫 RT 与粒子数量在移动端自动降级
- [x] Chrome / Edge / Safari / Firefox 控制台无 uncaught error
- [x] 移动端触控与面板操作不受新增系统影响
