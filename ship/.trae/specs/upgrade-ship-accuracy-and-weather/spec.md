# 泉州宋船模型 · 史料校核 / 环境系统 / 交互打磨 Spec

## Why

上一轮把页面从「像船的模型」升级为「可拆解的构件集合」，但仍有三类明显缺口：

1. **模型自证不足**：构件只有树种和尺寸文字，没有可点击的史料出处；图层树仍是 `QS_Planking_Outer_P01_S01` 这类英文 ID，不符合「按零件、位置分类、全部中文」的要求；船尾端面、残深基准等历史信息没有落位，也无法自证「无意外镂空、无多余部件」。
2. **环境是写死的**：太阳、雾、海况、浮力参数都不可调，画面偏暗、海面偏平，谈不上「真实」，也没有天气概念。
3. **交互是瞬时的**：选中、隔离、模式切换都是直接显隐，没有参考项目 `train/index.html` 那种缓动飞行、淡入淡出和卡片过渡。

本轮目标：模型能被逐件追问「这个数字从哪来」，环境能被逐项调到满意，交互全程「丝滑」。

## What Changes

- **几何闭合与自检**：补 `尾封板` 封闭船尾；统一壳板上下收边，消除透缝；校正舵承座 / 桅座 / 保寿孔 / 肋骨 / 舱壁的接触关系；新增「残深 1.98 m」参考线；新增运行时模型自检（退化构件、越界构件、重复 ID、未登记网格）。
- **史料档案层**：每个构件增加 `cnName`（中文名）、`cnPath`（中文层级路径）、`dimTable`（逐项尺寸表）、`sources`（出处链接数组，新窗口打开）。新增右上角「出处」页，汇总《泉州湾古船陈列馆导览》《福建省文物局·南宋海船残体》等来源。
- **中文图层树**：按「结构系统 → 部位/舷别 → 构件」三级中文分类，替换英文 ID；加搜索框与逐级折叠。
- **环境系统**：新增天空穹顶与太阳/月光；时间（0–24 h）、太阳高度/方位、色温、雾、曝光、环境光可调；天气预设（晴 / 多云 / 薄雾 / 黄昏 / 风暴）。
- **海况与物理**：浪高、波陡、波长、浪向、海水颜色、泡沫、水面半透可调；重力加速度 g、浮力刚度/阻尼、物理暂停、姿态复位可调。
- **交互动画**：选中/取消用 easeInOutCubic 相机飞行并记忆上一次视角；悬停高亮；隔离与模式切换淡入淡出；爆炸视图带阻尼缓动；面板可折叠、可一键复位视角。
- **BREAKING**：原右侧单列长面板改为「环境 / 结构 / 显示 / 出处」四个标签页；`拆解与显示` 独立区块并入「显示」页。

## Impact

## ADDED Requirements

### Requirement: 几何闭合与模型自检

系统 SHALL 保证船体外壳在可见范围内闭合：船尾以 `尾封板` 封闭（自尾龙骨上表面沿尾剖面升至舷侧），壳板列上下缘以收边条封闭，MUST NOT 出现可透视内部的意外镂空。舵承座、桅座、保寿孔、肋骨、舱壁 MUST 与相邻构件保持接触，MUST NOT 悬空或大面积互穿。

系统 SHALL 在构建完成后运行自检并在「显示」页给出结果：

- 退化构件（包围盒任一维 < 0.002 m）
- 越界构件（包围盒超出包络 ±0.15 m）
- 重复构件 ID / 未登记到集合的网格
- 空洞标记：壳板区域采样点是否都能命中船体

#### Scenario: 自检结果
- **WHEN** 首次渲染完成
- **THEN** 「模型自检」显示 4 项全绿；任一项异常时列出具体构件名，且不静默修复

#### Scenario: 船尾不再透空
- **WHEN** 切到「尾部正视」并关闭水面半透
- **THEN** 船尾被尾封板封住，看不到船体内部

### Requirement: 构件史料档案

每个构件 SHALL 携带 `cnName`、`cnPath`、`dimTable`、`sources` 四项元数据。

- `cnName`：中文名称（如「第 07 号舱壁」「左舷第 03 列外层壳板·艉段」）。
- `cnPath`：中文层级路径（如「三重壳板 / 外层 / 左舷 / 第 03 列」）。
- `dimTable`：逐项尺寸（名称、数值、单位、来源标注「实测 / 推演」）。
- `sources`：至少 1 个出处链接，SHALL 以 `target="_blank" rel="noopener noreferrer"` 打开。

#### Scenario: 点击构件
- **WHEN** 点击任意构件
- **THEN** 信息卡显示中文名与中文路径、尺寸表、来源徽标，并列出可点击的出处链接

#### Scenario: 出处页
- **WHEN** 打开「出处」标签
- **THEN** 汇总全部来源条目，标注每条支撑了哪些构件类别

### Requirement: 中文图层树

图层树 SHALL 全部使用中文，且按「结构系统 → 部位/舷别 → 构件」三级组织，例：

```
龙骨系统
  主龙骨 / 尾龙骨 / 首柱 / 榫合接头
水密舱壁
  第 01–12 号舱壁 / 橡木底列 / 舱段间距
抱梁肋骨
  左舷 / 右舷 → 逐舱肋骨
三重壳板
  内层 / 中层 / 外层 → 左舷 / 右舷 → 第 01–13 列
舵系 / 桅座 / 保寿孔 / 复原推演层
```

树 SHALL 支持搜索（按中文名、编号、树种），并显示各级构件计数。

#### Scenario: 搜索
- **WHEN** 在搜索框输入「舱壁」
- **THEN** 树中只保留命中的舱壁类构件及其父级，计数同步

### Requirement: 光照与天空

系统 SHALL 提供天空穹顶（渐变 + 太阳/月亮光斑）与可调光照：

- 时间 0–24 h：驱动太阳方位/高度、色温、天空渐变、雾色与强度。
- 太阳高度、方位、强度、色温可独立微调；环境光强度、曝光可调。
- 阴影质量（关 / 低 / 高）。

#### Scenario: 黄昏
- **WHEN** 时间调到 18:30
- **THEN** 太阳压低、天空转暖橙、海面高光拉长、雾色变暖

### Requirement: 天气与海况

系统 SHALL 提供天气预设「晴 / 多云 / 薄雾 / 黄昏 / 风暴」，一键写入光照、雾、海况与相机曝光参数；并提供细调：

- 浪高、波陡、波长倍率、浪向
- 海水深/浅色、透明度、泡沫强度
- 水面半透开关

#### Scenario: 风暴
- **WHEN** 点击「风暴」
- **THEN** 浪高与波陡上升、天空压暗、雾变浓、船体起伏明显，参数滑杆同步到新值

### Requirement: 重力与浮力

系统 SHALL 把重力与浮力参数暴露为可调项：重力加速度 g（默认 9.81）、浮力刚度、阻尼、物理暂停、姿态复位。

#### Scenario: 调低重力
- **WHEN** g 从 9.81 调到 3.0
- **THEN** 波浪传播变慢、船体起伏与摇摆更迟缓，参数在面板可见

#### Scenario: 暂停与复位
- **WHEN** 点击「物理暂停」
- **THEN** 船体保持当前姿态不再摇摆；点击「复位姿态」后回到水平并恢复

### Requirement: 平滑交互

系统 SHALL 使用缓动动画完成以下切换，禁止硬切：

- 选中构件：easeInOutCubic 相机飞行至构件（约 0.9 s），退出时回到选中前视角。
- 悬停：光标所在构件高亮，移出恢复。
- 隔离：非目标构件淡出至不可见（约 0.35 s）。
- 残体 / 复原切换：推演层透明度渐变。
- 爆炸视图：滑杆值经阻尼插值后再作用于构件位移。
- 面板：可折叠/展开，提供「复位视角」按钮。

#### Scenario: 选中与退出
- **WHEN** 点击壳板再点关闭
- **THEN** 镜头先飞近该板，关闭后沿同一路径飞回原位，全程无跳变

## MODIFIED Requirements

### Requirement: 信息卡

原信息卡（左下列表）SHALL 升级为右侧详情卡（参考 `train/index.html` 的 `#card`）：顶部中文名 + 来源徽标，次级行显示中文路径与树种，主体为尺寸表，底部为「出处链接 / 隔离 / 聚焦 / 关闭」。卡片以位移 + 淡入过渡出现，关闭时反向过渡。

### Requirement: 尺寸审计

原 11 项审计 SHALL 保留目标值与容差，并增加「模型自检」四项；审计超差仍只标红不修正。

### Requirement: 海面材质

原单一 Gerstner 着色器 SHALL 升级为：天空反射（按太阳方向与天空渐变近似）、菲涅尔、泡沫（按波峰与噪声）、按透明度混合、雾融合；并受环境/天气参数驱动。

## REMOVED Requirements

### Requirement: 英文 ID 图层树

**Reason**: 不符合「全部使用中文名称」，且无法按部位快速定位。

**Migration**: 英文 ID 保留为内部 key 与信息卡副标题，界面一律显示中文名与中文路径。
