# Checklist

## 船尾闭合
- [x] 尾封板外轮廓覆盖最外层壳板（含搭接阶），向内挤出 0.24 m
- [x] 壳板向尾端延伸并与尾封板重叠 30 mm
- [x] 尾端环形封边封闭三层板端面台阶
- [x] 尾封板内侧水密隔板从龙骨面覆盖到舷侧
- [x] 船尾正视、水线视角、船内俯视均无透光缝隙
- [x] 新构件在图层树与详情卡中可见（尾封板 / 尾端环形封边 / 尾舱水密隔板）

## 参数区间与输入
- [x] 28 个数值参数同时有滑杆与数字输入框
- [x] 滑杆与数字框双向同步（滑杆 60 ↔ 数字 0.60）
- [x] Enter 与失焦均提交，越界自动夹取并回显（999 → 1.2）
- [x] 空值 / NaN 回退到上一有效值，不产生 NaN 画面
- [x] 量程按规格表统一：amp 0–1.2、chop 0–1.2、wl 0.5–2.0、alpha 0.2–1.0 等
- [x] 旧 `qs-water` 越界值加载时自动收敛

## 自定义预设
- [x] 可命名保存当前全部参数
- [x] 可应用、覆盖、删除自定义预设
- [x] 刷新后预设列表与参数均保留（`qs-presets`）
- [x] 「恢复默认」可用且不影响内置 7 档天气

## 云与闪电
- [x] 天空可见程序化云层，云量随 `cloud` 变化
- [x] 云的漂移速度与方向随 `windSpeed / windDir` 变化
- [x] 闪电时天空与场景短时变亮（`uFlash` + 半球光 + 曝光）
- [x] `lightning = 0` 时不再出现闪电

## 降雨
- [x] 大雨下可见成片雨幕，方向与风向一致
- [x] 细雨下雨滴稀疏、更短、更淡
- [x] `rain = 0` 时雨幕完全隐藏且无性能开销
- [x] 水面出现随雨强变化的细微扰动

## 天气预设
- [x] 天气按钮为 7 档：晴 / 多云 / 小雨 / 大雨 / 薄雾 / 黄昏 / 风暴
- [x] 各档在云量、雨强、风速、浪高、能见度上可辨识
- [x] 切换天气约 2 s 平滑过渡（云、雨、雾、光照、曝光），无上一档雨幕或闪电残留
- [x] 风暴自动触发闪电与雷声，雨声明显增强
